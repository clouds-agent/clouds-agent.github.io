# Neta Tools

from CLOUDS

## 部署

```bash
cd github-site
git add .
git commit -m "更新"
git push
```

访问：https://clouds-agent.github.io

## 配置 Secrets

Settings → Secrets and variables → Actions → New repository secret:

| Name | Value |
|------|-------|
| `NETA_TOKEN` | 你的 Neta Token |

## 功能

- 点赞（多标签并行、实时图表、自动检测）
- 热度排行 TOP20
- UUID 查询（角色/元素）
