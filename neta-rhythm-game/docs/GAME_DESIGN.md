## 一、核心概念

### 游戏名称
（待定）

### 一句话定位
一款以 **6轨伪4k + SV（速度变化）+ 动态轨边切换** 为核心玩法的音游。

### 设计理念
- 本质是4k音游，但通过 **0/5自由轨的动态接入** 和 **SV速度变化**，创造出"伪6k"的独特体验
- 轨道边的亮起/熄灭不是装饰，而是 **玩法的一部分**，提示玩家当前有效轨域
- SV 不仅是变速，更是 **音乐情感的表现工具**——谱面的快慢与音乐同步起伏

## 二、游戏玩法

### 2.1 轨道系统

#### 轨道编号
| 编号 | 角色 | 说明 |
|------|------|------|
| 0 | 左自由轨 | 默认熄灭，特定谱段亮起 |
| 1 | 主轨左 | 默认亮起 |
| 2 | 主轨中左 | 默认亮起 |
| 3 | 主轨中右 | 默认亮起 |
| 4 | 主轨右 | 默认亮起 |
| 5 | 右自由轨 | 默认熄灭，特定谱段亮起 |

六个轨道紧贴排列，共 **7条轨边**。

#### 轨边发光机制

- 当某轨道 **即将/正在落下按键** 时，该轨道两侧的两条边呈 **金色**
- 金色不是纯色线条，带有 **微弱发光效果**（glow）
- 发光跟随按键实时动态变化

#### 轨边亮起/熄灭（核心机制）

初始状态：1-4轨的轨边亮起，0/5轨熄灭。

**典型切换模式：**

| 模式 | 描述 | 触发示例 |
|------|------|----------|
| 右→左扩展 | 4轨熄灭，0轨亮起 | 歌曲从标准4k转入更宽的谱域 |
| 左→右扩展 | 1轨熄灭，5轨亮起 | 同上，对称 |
| 渐变 | 轨边以渐变形式由上至下亮起/熄灭 | 视觉过渡，给予玩家适应时间 |
| 瞬切 | 直接亮起/熄灭 | 突发效果 |

- 熄灭后 **完全消失**（不是黑线，是整条边消失）
- 亮起以 **渐变形式由上至下** 出现
- 熄灭同理 **由上至下** 消失
- 由制谱器在时间轴上精确控制：**何时亮/灭、持续多久**

#### 判定线

- 每个轨道 **底部都有独立的判定线**
- 共6条判定线，分别对应6个轨道
- 判定区间暂留待后续定义

### 2.2 按键类型

| 类型 | 说明 | 判定 |
|------|------|------|
| 单点（Tap） | 到达判定线时点击 | 接住算1个note |
| 长按（Hold/长条） | 到达判定线时按住，保持到尾部 | **无尾判**，接住整个算1个note |

- 无滑动（Slide）、无拖拽（Drag）
- 适配手机、平板、电脑三种输入方式

### 2.3 SV 系统（Speed Variations）

**定义：** 通过制谱时设定按键下落速度，产生谱面忽快忽慢的效果。

**关键性质：**
- SV 是 **谱面中的一种表演**，不是整个谱面的配置
- 可以让 **部分按键** 拥有不同的下落速度
- 也可以让 **谱面局部** 整体改变速度来匹配音乐情感

**缓动函数：**
- 预设 **24种缓动效果**（easing functions）
- 除自带预设外，支持 **自定义函数**
- 理想实现：在 1.0x 的直线上 **点击设点 → 拖动调节**（可视化函数编辑器）

### 2.4 Camera 参数

- 控制 **近似观察谱面的摄像头离谱面的距离**
- 初始值：100
- Camera 偏大时 → 轨道和按键看起来 **更小**（等比缩放）
- Camera 偏小时 → 轨道和按键看起来 **更大**
- 需要通过函数/时间轴控制，配合音乐高潮/低谷产生视觉冲击

### 2.5 Censor（黑色晕影）

- 形成 **黑色晕影** 效果
- 可调节距离数值
- 可选择方向：
  - 上方
  - 左右两侧
  - 四周
- 配合剧情或音乐氛围使用

## 三、制谱器（Chart Editor）

### 3.1 界面布局

```
┌─────────────────────────────────────────────────────────┐
│  🎵 [曲目名称]          BPM: 180 ▼     速度: 1.0x ▼    │
├──────────┬──────────────────────────┬───────────────────┤
│          │                          │   SV 时间轴       │
│  工具栏  │    6k 制谱主界面          │   （6轨）         │
│          │                          │                   │
│ [单点]   │   0 | 1 | 2 | 3 | 4 | 5  │   ┌───┐          │
│ [长按]   │   ──┼──┼──┼──┼──┼──    │   │///│          │
│ [橡皮]   │     │  │  │  │  │  │     │   └───┘          │
│ [选择]   │     ▼  ▼  ▼  ▼  ▼  ▼     │                   │
│          │   ════ 判定线 ════       │   轨边时间轴      │
│          │                          │   （7条边）       │
│          │                          │                   │
│          │                          │   ▄▄▄▄            │
├──────────┴──────────────────────────┴───────────────────┤
│  ▶ 播放  ⏸ 暂停  ⏹ 停止  ⏩ 变速  ⏪ 后退              │
│  ━━━━━━━━━━━━ 音频波形 ━━━━━━━━━━━━                    │
│  时间: 01:23.45                                        │
├─────────────────────────────────────────────────────────┤
│  💾 保存  📂 导入  📤 导出  👁 预览                     │
└─────────────────────────────────────────────────────────┘
```

### 3.2 基础功能

| 功能 | 说明 |
|------|------|
| BPM 设置 | 支持设置基础 BPM |
| 6k 制谱界面 | 0-5 六轨可视化编辑 |
| 小节节奏划分 | 1/1, 1/2, 1/3, 1/4, 1/5, 1/6, 1/8, 1/12, 1/16 等 |
| 手动填写划分 | 可自定义输入分数值 |
| 音频上传 | 上传本地音频文件 |
| 音频播放 | 在编辑器内播放音频 |
| 变速播放 | 0.5x ~ 2.0x 变速播放（不影响 BPM 设定） |
| 谱面保存 | 保存为单一文件 |
| 谱面导入 | 从文件导入谱面 |
| 谱面导出 | 导出为单一文件 |

### 3.3 谱面文件格式

- **单一文件** 整合所有数据
- 格式：JSON（可扩展）
- 包含：
  - 元数据（BPM、曲名、曲师等）
  - Notes 数据（时间、轨道、类型、长度）
  - SV 曲线（时间轴上的速度函数）
  - 轨边状态（时间轴上的亮灭控制）
  - Camera 曲线（时间轴上的摄像头距离）
  - Censor 配置（时间、方向、距离）
  - BPM 变化（局部 BPM 切换）

### 3.4 SV 时间轴

**位置：** 制谱界面右侧，与6轨主界面并列

**功能：**
- 6轨独立 SV 控制（每条轨道可有不同的速度曲线）
- 预设 24 种缓动函数
- **可视化函数编辑器**：在基准线上点击设点 → 拖动调节
- 控制按键特别下落速度
- 控制谱面局部整体速度变化

### 3.5 轨边时间轴

**位置：** SV 时间轴下方或独立面板

**功能：**
- 7条轨边的亮起/熄灭控制
- 可调节：
  - **何时**亮起/熄灭（精确到毫秒）
  - **持续多久**（例如 2:00 处亮起，持续 0.5s）
  - **渐变方向**（由上至下 / 瞬切）

### 3.6 Camera 函数控制

- 通过函数/曲线控制 Camera 距离
- 可视化编辑，支持设点拖动
- 配合音乐高潮产生视觉冲击

### 3.7 谱面预览

| 功能 | 说明 |
|------|------|
| 从头预览 | 从时间 0:00 开始完整预览 |
| 选定预览时间 | 跳转到指定时间点开始预览 |
| 预览速度 | 可调节预览播放速度 |
| 音频联动 | 预览时所有轨道与音频同步运动 |
| 制谱时联动 | 播放音频时，所有轨道一起联动运动 |
